# Vantage Golf — sitio web

Landing page de **Vantage Golf · Performance Rope Golf Cap**.

- Pelota de golf 3D que sigue el scroll (Three.js)
- Modelo 3D de la gorra que se arma pieza por pieza, con vista libre
- Sección 360° que abre con el video de ensamblaje controlado por el scroll
- Smooth scroll (Lenis) y animaciones con GSAP ScrollTrigger

Sitio estático: `index.html` + `img/`, `models/`, `seq/`. Publicado con GitHub Pages.
